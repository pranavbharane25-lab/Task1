# Cloud Computing & DevOps - Task 1

## Overview
Hosted a static single-page portfolio on AWS S3 and served it securely via Amazon CloudFront with HTTPS[cite: 1, 2].

## Steps Taken
1. Created local project structure (`index.html`, `styles.css`, `assets/`)[cite: 2].
2. Initialized Git, committed files, and pushed them to GitHub[cite: 1, 2].
3. Created an S3 bucket and enabled Static Website Hosting[cite: 2].
4. Configured S3 Bucket Policy for public read access (`s3:GetObject`)[cite: 1, 2].
5. Created an AWS CloudFront distribution with S3 as origin and enforced HTTP to HTTPS redirection[cite: 1, 2].
